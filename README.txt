Inn Jan Photography 个人摄影作品集网页

打开方式：
1. 解压 zip 文件。
2. 双击 index.html 即可在浏览器打开。
3. 如果要修改文字，直接用 VS Code / 记事本打开 index.html 搜索对应文字即可。
4. 图片位于 assets 文件夹，替换同名图片即可更新作品。

已包含功能：
- 首页六个艺术化栏目导航
- 首页全屏封面
- 精选展墙
- 作品分类筛选
- 关键词搜索
- 点击图片全屏放大
- 键盘左右切换 / Esc 关闭
- 背景音乐按钮（浏览器合成音，不依赖音频文件）
- 深色/浅色主题切换
- 联系我区域与邮件表单
- 返回顶部与滚动进度条
- 星尘谱艺术小游戏
- 数象仪高级艺术计算器与动画导出
- 色温档案本地照片滤镜
- 时隙仪毫秒钟与时间标本
- 介质炼金室：DOCX/PPTX 转 PDF、视频转 GIF/MP3、图片格式转换
- PDF 工具：多份 PDF 排序合并、自定义文字水印
- 压缩工具：多文件打包 ZIP、ZIP 安全解包、图片/视频压至目标体积范围

介质炼金室说明：
- 文件只在浏览器本地处理，不会上传到服务器。
- Office 文件先生成页面预览，再由浏览器逐页生成并直接下载 PDF，不经过打印面板。
- 同时保留“打印保存 PDF”入口，用户可以自行选择生成方式。
- PPT 动画、宏、缺失字体及极复杂的 Office 版式可能被静态化或简化。
- 视频转换会占用设备内存，手机上建议使用较短片段。
- 视频压缩首次使用会加载站内自带的转码引擎，整个过程仍在本地完成。
- 压缩包当前支持通用 ZIP；RAR 和 7Z 暂不在浏览器兼容范围内。
